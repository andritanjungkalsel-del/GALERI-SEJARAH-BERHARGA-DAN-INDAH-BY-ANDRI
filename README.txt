GALERI SEJARAH BERHARGA DAN INDAH — E2EE
==========================================
Versi upgrade dengan penyimpanan foto, video, musik, file umum, dan catatan bergambar.

Semua konten utama dienkripsi di browser memakai Web Crypto API (AES-GCM 256-bit) sebelum dikirim ke Supabase.

File:
- index.html
- style.css
- script.js
- SUPABASE_SETUP.txt
- README.txt

Ikuti SUPABASE_SETUP.txt untuk database, Storage, policy, dan konfigurasi.
